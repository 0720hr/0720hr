## What I'm working on

A security home lab I built and then attacked, to see what my defences actually catch. Four projects, each written up with the problems I hit and how I checked the fix:

- **[Wazuh SIEM Detection Lab](https://github.com/0720hr/hr_range/tree/main/01-wazuh-siem-lab)**: detects a full SSH attack chain and blocks the attacker automatically
- **[SOC Automation](https://github.com/0720hr/hr_range/tree/main/02-soc-automation)**: triages alerts, enriches attacker IPs against threat intel, and contains account takeovers
- **[Endpoint Detection with LimaCharlie](https://github.com/0720hr/hr_range/tree/main/03-limacharlie-edr)**: runs the same attack past an EDR and a SIEM, side by side
- **[Adversary Emulation](https://github.com/0720hr/hr_range/tree/main/04-adversary-emulation)**: runs seven ATT&CK techniques, finds coverage gaps, and writes custom rules to close them

All four live in [0720hr/hr_range](https://github.com/0720hr/hr_range).
